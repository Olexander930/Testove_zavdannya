Написаний скрипт мовою PHP, читає неструктурований текстовий файл і перетворює його на багаторівневий структурований JSON
Як це працює
Скрипт читає файл рядок за рядком і завдяки збереженню стану сортує дані
1. Знаходить головні категорії типу заголовки
2. Визначає підкатегорії завдання, шляхи виконання, очікувані результати
3. Очищає рядки від зайвих символів і записує їх у відповідний масив
